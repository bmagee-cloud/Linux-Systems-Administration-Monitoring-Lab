Linux Systems Administration & Monitoring Lab

A hands-on Linux systems administration project focused on configuring, securing, automating, and monitoring Linux-based infrastructure. The project demonstrates practical experience managing users and permissions, SSH access, systemd services, packages, processes, storage, networking, firewalls, scheduled tasks, and system logs.

Bash scripting is used to automate routine administrative tasks, perform system health checks, monitor resource utilization, and support proactive troubleshooting. The project also documents configuration procedures, troubleshooting scenarios, security practices, and operational improvements commonly encountered in production IT environments.
